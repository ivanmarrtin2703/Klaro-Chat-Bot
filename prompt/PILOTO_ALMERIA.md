# Piloto Almería

## Objetivo
1 salón real (2–6 sillas) usando CitaClara en producción durante 2 semanas.

## Protocolo
1. Validar dolor WhatsApp (mensajes noche / precios).  
2. Recoger carta + staff + horarios (`ALTA_CLIENTE.md`).  
3. Setup reducido opcional (ej. 349 €) o 1er mes gratis + setup 549 €.  
4. Go-live con número bot o número del salón en Cloud API.  
5. Revisar conversaciones fallidas cada 48h.  
6. Pedir testimonio + captura para landing.

## Éxito
- ≥5 citas agendadas por el bot en 14 días, o  
- Dueña confirma que deja de contestar FAQs repetidas.
