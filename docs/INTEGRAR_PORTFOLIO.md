# Integrar en Mi Página Web

1. Demo estática: `Mi Págna Web/public/demos/citaclara/`  
2. Logo: `public/assets/projects/citaclara/logo.svg`  
3. Seed: `npm run seed:citaclara` (con portfolio en local + `ADMIN_PIN` en `.dev.vars`)  
4. Variables opcionales:
   - `CITACLARA_LIVE` = URL Pages de la landing  
   - `CITACLARA_REPO` = URL GitHub  

Limpiar restos antiguos `salon-responde` del portfolio.
